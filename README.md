# ContaComigo (DAM)

## Descrição
Aplicação móvel Android (nativa) para gestão de despesas, com partilha por utilizadores, autenticação,
controlo de acessos e anexação de recibos.

## Requisitos de Avaliação (Checklist)
- [ ] Interface em Português (PT-PT)
- [ ] Uso de hardware com sentido para o tema (ex.: câmara para recibos / GPS)
- [ ] Interação com API REST (sem Firebase ou equivalente)
- [ ] Autenticação
- [ ] Controlo de acesso a recursos (perfis/roles)
- [ ] Validações em inserção e edição
- [ ] Confirmação/validação em remoção
- [ ] Mensagens de erro adequadas
- [ ] Armazenamento local (dados necessários)
- [ ] Ecrã "Informações" acessível a partir do ecrã inicial (curso/UC/ano, autores com foto, libs e fontes)
- [ ] Publicação na Google Play (conta fornecida pelos docentes)
- [ ] GitHub com evolução visível (commits frequentes e justificáveis)

## Estrutura do Repositório

- `/server` - API (REST)
